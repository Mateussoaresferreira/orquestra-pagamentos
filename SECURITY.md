# Política de segurança

Não publique vulnerabilidades em uma issue aberta.

Ao relatar um problema, inclua o componente afetado, impacto, passos mínimos para reprodução e uma sugestão de mitigação, sem anexar tokens, credenciais ou dados pessoais reais.

O ambiente Docker utiliza credenciais conhecidas e autenticação desabilitada para desenvolvimento. Ele não deve ser exposto à internet. Consulte `docs/SEGURANCA.md` antes de qualquer implantação.
